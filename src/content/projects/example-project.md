Each project is a Markdown file in `src/content/projects/`. The front matter at the
top (between the `---` lines) feeds the cards; everything below becomes the project page.

## What to write here

- The problem and the context
- What you built, and with what
- What was hard, and what you'd do differently

Set `draft: true` to hide a project while you're writing it, and `lab: /lab/something/`
to link it to an interactive demo.
